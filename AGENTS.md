# Agent instructions

## Выпуск через Stakan

Для выпуска и диагностики деплоя применять [stakan-deploy](.zcode/skills/stakan-deploy/SKILL.md). Этот путь заменяет прежние инструкции про Actions/прямой SSH-деплой; конфигурация сервера устанавливается оператором отдельно. Приложение работает через systemd. Выпуск переключает каталог проверенного артефакта через current; прежний EnvironmentFile и отдельная MongoDB сохраняются. Проверки используют временную replica set и тестовые данные, а не рабочую базу.
